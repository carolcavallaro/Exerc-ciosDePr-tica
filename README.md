# 🐍 Exercícios de Prática — Python

Este repositório reúne os exercícios práticos desenvolvidos durante as minhas aulas do curso **Fundamentos do Python 1** no **Senai Americana**. O objetivo principal é consolidar a lógica de programação, aplicar boas práticas de código e desenvolver soluções estruturadas para cenários do mundo real.

---

## 💻 Tecnologias & Ferramentas

* **Linguagem:** Python 
* **Ambiente:** Jupyter Notebook (`.ipynb`) & Scripts Executáveis (`.py`)
* **Ferramentas:** VS Code / Git & GitHub

---

## 📂 Conteúdo do Repositório

Abaixo está a descrição detalhada do foco prático e dos conceitos abordados em cada arquivo:

| Arquivo | Descrição / Foco Prático |
| :--- | :--- |
| `01PDFIntro_exerciciosString_3.4.py` | **Manipulação Básica de Strings:** Tratamento de entradas do usuário utilizando métodos como `.upper()` e `.replace()` para remoção de espaços em branco. |
| `02algoritmoDoPureDeBatatas.py` | **Lógica Sequencial e Operações Simples:** Exercício de tomada de decisão com `if/else`, operações aritméticas de subtração/soma e conversão de tipos (`int`). |
| `03desafioDaIdade.py` | **Cálculo de Idade e Saída Formatada:** Leitura de dados do usuário, cálculo simples de ano vigente e exibição com *f-strings* e quebras de linha (`\n`). |
| `04descontoDeIngressos.py` | **Regras de Negócio e Operadores Matemáticos:** Verificação de par/ímpar via resto da divisão (`%`), estruturas condicionais compostas (`if/elif/else`) e formatação de moeda (`:.2f`). |
| `05_email.py` | **Processamento e Slicing de Strings:** Extração de partes de um e-mail utilizando `.split()`, verificação de domínio com índices negativos e inversão de texto (`[::-1]`). |
| `05correcao_email.ipynb` | **Refatoração e Testes Interativos:** Versão em *Jupyter Notebook* para correção do exercício anterior. |
| `06calculadoraDeDescontos.py` | **Aplicação Completa de Algoritmo:** Função personalizada com `def` e `return`, tratamento de entradas com `.strip()`, `.lower()` e `.upper()`, controle de fluxo com `while True`/`break` e regras de frete via operadores booleanos. |
| `07logisticaEventos.py` | **Manipulação de Listas e Arredondamento:** Gestão de itens em listas (`.append()`, `.insert()`, `.pop()`), ordenação com `.sort()` e cálculo de capacidade/custo logístico para eventos. |
